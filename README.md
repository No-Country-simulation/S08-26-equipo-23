# 🩺 HealthDemand — Sistema de Predicción y Gestión de Demanda de Turnos

## 📌 Descripción del Proyecto
HealthDemand es una plataforma de análisis predictivo diseñada para anticipar la demanda de turnos médicos en centros de salud. El sistema utiliza datos históricos sintéticos contextualizados localmente para detectar picos de demanda, optimizar la asignación de profesionales y reducir tanto la saturación como la subutilización de recursos.

## 🎯 Objetivo del Negocio
Transformar la planificación médica de un enfoque **reactivo** ("¿cuántos pacientes tuvimos?") a uno **preventivo** ("¿cuántos esperamos y cómo nos preparamos?"), permitiendo:
- Anticipar incrementos de demanda por especialidad y barrio.
- Reducir listas de espera mediante overbooking inteligente basado en tasas de ausentismo.
- Optimizar costos operativos evitando recursos ociosos.

## ️ Stack Tecnológico
- **Data Science:** Python, Pandas, Scikit-Learn
- **Datos:** Dataset sintético generado con estacionalidad argentina y perfiles socioeconómicos de CABA.

## 📊 Características del Dataset
El dataset incluye variables clave para el modelado:
- **Geolocalización:** 10 barrios reales de CABA con niveles socioeconómicos diferenciados.
- **Estacionalidad Local:** Picos de gripe en invierno, alergias en primavera y baja demanda en vacaciones de verano.
- **Métricas de Negocio:** Tasa de ausentismo, cancelaciones, demanda no atendida y nivel de saturación.
